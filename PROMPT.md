I want to create an iOS iPhone app that I can use to memorize and practice basic blackjack strategy.

The app should have two tabs. In one tab, the app presents my two cards and the dealer's showing card, and lets me choose Hit, Stand, Split, or Double. After I choose, it tells me whether I was right or wrong, and if wrong, provides some advice for remembering the correct play.

The other tab contains reference material like the strategy chart.

The app only has to support the most recent versions of iOS and Xcode. It will not be distributed in the app store. The name should be "Blackjack Strategy" and the app ID is net.kristopherjohnson.blackjack_strategy.

I want to start with an MVP with minimal functionality. We can expand the capabilities later.
